# 保费补退定义

每份保单有且仅有一条issue基线。change按effective、责任、version选版；同生效日同版本矛盾拒绝。cancel必须引用同保单的change，取消整份变更，不按录入顺序覆盖。区间为[start,end)。年度保费按所在自然年365或366日拆分，跨年强制切段。先求每段精确保费，再最大余额法分配到分，使段合计等于保单总额。paid为已收金额，总应收减已收为补退额，正数补缴、负数退费。

## 通用采信约定

CSV按UTF-8 BOM、UTF-8、GB18030回退，保留逻辑记录结束行号；引号内换行由CSV解析。重复表头单独计数，列数不齐隔离。编码与ID按字符串保形。缺失哨兵为 `-`、`N/A`、`NULL`、`未知` 与空串；不得作为零。数值先NFKC归一、去千分位，再用Decimal。日期采用ISO；时间必须带偏移并转UTC。空文件、全空行、仅表头分别返回EMPTY_FILE、BLANK_FILE、HEADER_ONLY。

重复键为(id,version)，完全相同行去重；同键内容冲突则整组隔离，不取最后一行。行数对账：输入=采纳+隔离+空行+重复表头+完全重复。运行幂等键由输入字节、参数与规则版本计算。

## 银行来账

日终一笔银行来账可对应多张保单，附言只列出部分保单号；已匹配保单的补退需当日划款。
来账经 `parameters.remittances` 传入，每笔含 `id`（来账号，必填）、`amount`（到账金额，精确到分）、
`date`（ISO 到账日）、`memo`（原文附言）、`policies`（显式保单清单）、`allocations`（逐保单金额）。

### 分配裁决

1. **分配范围** = 附言/显式清单中的保单号 ∩ 本批已采信保单。未列出的保单不吸收来账。
2. **退费保单**（补退为负）与**已结清保单**（补退为零）不吸收来账。
3. 只有**归属可说明**的金额才允许分配，且每张保单核销额不超过其应补额：
   - 给出逐保单金额时按该金额核销（依据 `EXPLICIT`）；
   - 剩余金额只剩一张待补缴保单时，可部分核销（依据 `SOLE_REFERENCE`）；
   - 剩余金额对应多张待补缴保单时，按来账声明顺序逐张足额结清（依据 `DECLARED_ORDER`），
     第一张无法足额结清的余额不再拆分，全部转入暂挂（`INSUFFICIENT`）。
4. **暂挂款** = 整笔到账 − 已分配，保留原始来账（号、到账日、附言、金额、内容哈希）与
   匹配依据（命中的保单、未命中的引用 `unmatched_refs`），不回摊到任何已匹配保单。
5. 恒等式：`整笔到账 = Σ已分配 + 暂挂`；`分配后实收 = 原实收 + 已分配`；
   `分配后补退 = 原补退 − 已分配 = Σ每张保单净额`；`Σ已分配 ≤ Σ正补缴额`。
6. 金额超过两位小数、逐保单金额超过应补额或合计超过到账金额，均拒绝。

### 幂等与替换

同一来账号（`id`）内容完全一致视为重复导入：只计算一次，`duplicates` 计数，已分配金额不增加。
同一来账号内容冲突直接拒绝（`CONFLICT`），不取最后一行。批次幂等键忽略来账顺序与完全重复项，
因此重复导入或匹配重试复用同一批次。

替换来账用 `POST /api/runs/<id>/remittance`，须提交当前 `version`。成功时生成接替批次并标记
`parent`/`replaced_by`，旧批次正文、版本与分配原样保留、仍可下载解释原来账；接替批次号仍由
输入+参数+规则版本计算，因此之后再导入同一来账会落到接替批次，不会多出一份已分配金额。
版本不符、批次已替换或重算校验失败时不写任何内容，旧版保持不变。
